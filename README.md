# Auralis

Auralis is a simple full‑stack web application that provides an AI‑powered voice‑based safety system.

## Overview
- **Frontend** – React (Vite) that continuously listens to the microphone using the Web Speech API. Detects danger keywords (`help`, `danger`, `emergency`, `save me`) and triggers an SOS alert. The alert can be cancelled by saying `safe` or by pressing the manual SOS button.
- **Backend** – FastAPI with in‑memory storage (list) for trusted contacts and static dummy data for nearby hospitals and police stations.
- **Run locally** – No external APIs are required.

## Project Structure

## Prerequisites
- Python 3.9+ (recommended 3.11)
- Node.js 20+ and npm
- A modern browser that supports `SpeechRecognition`/`webkitSpeechRecognition`

## Setup
### 1. Clone / create the project folder
Create the folder `C:\Users\srira\.gemini\antigravity\scratch\auralis` and place the files from this repository there.

### 2. Backend
```bash
cd backend
python -m venv venv
venv\Scripts\activate   # on Windows
pip install -r requirements.txt
uvicorn main:app --reload   # runs on http://127.0.0.1:8000
```
The backend provides the following endpoints:
- `GET /contacts` – list contacts
- `POST /contacts` – add a contact `{ "name": "…", "phone": "…" }`
- `GET /hospitals` – dummy list of hospitals
- `GET /police` – dummy list of police stations

### 3. Frontend
Open a new terminal:
```bash
cd ..\frontend   # go to the generated Vite project
npm install
npm run dev   # http://localhost:5173
```
The frontend automatically talks to the backend at `http://127.0.0.1:8000`.

### 4. Using the app
- Allow microphone access when the page loads.
- Speak any of the danger keywords – an SOS banner appears.
- Say "safe" to cancel the alert.
- Click **Manual SOS** to trigger the alert manually.
- Add trusted contacts via the simple form; they are stored in the backend.
- The dummy nearby hospitals and police stations are displayed below.

---
**Note:** The backend uses in‑memory storage, so contacts are lost when the server restarts. For persistence you can replace the list with a SQLite DB – the code is straightforward to adapt.
